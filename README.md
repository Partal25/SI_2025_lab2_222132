Барање 4
Да се напишат сите тест случаи според Every Statement критериумот.

Тест случаите кои треба да се извршат се следните:
Тест 1. Проверка дали allItems == null
Очекуваме да фрли исклучок RuntimeException: allItems list can't be null!
Проверуваме дали добро се фрла исклучокот

Тест 2. Проверува дали одреден производ е валиден без попуст
На пример ако додадеме allItems = [new Item("Coca cola", 2, 500, 0.0)],
очекуваме резултат sum += price * quantity = 200.0

Тест 3. Производ со попуст
На пример за allItems = [new Item("TV", 5, 200, 0.2)]
очекуваме резултат Попуст = 200 * 0.8 * 5 = 800, Казна = -30 => 770.0
